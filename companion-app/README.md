# GNDROiD Link — Companion App & Universal Receiver

[![Platform: Android 8.0+](https://img.shields.io/badge/Platform-Android%208.0%2B-brightgreen.svg)](#)
[![Port: 51880 / 51888](https://img.shields.io/badge/Port-51880%20%2F%2051888-blue.svg)](#)

The **GNDROiD Link** Companion App (`GNDROiD_Companion.apk`) transforms any Android smartphone, tablet, or Android TV device into a zero-latency wireless streaming node and remote receiver for the GNDROiD Windows Master Suite.

---

## ⚡ Key Features

1. **Pure Wireless Screen Mirroring (Zero USB Cable):**
   - High-throughput low-latency screen streaming directly over your local Wi-Fi / LAN on port `51880`.
2. **Android TV & Big-Screen Leanback Display Mode:**
   - Run GNDROiD on your Android TV / Google TV device to receive desktop or secondary mobile screens in 4K/1080p.
3. **1-Tap Permission Orchestration:**
   - Instantly grants Accessibility Input Injection, Floating Overlay Window, and Doze Battery Exemption for 24/7 background availability.
4. **Hardware & Connection Telemetry:**
   - Real-time battery status, CPU temperature, and sub-second heartbeat watchdog monitoring.

---

## 📥 Direct Download & Installation

The compiled production APK is located in this directory:
👉 **[`GNDROiD_Companion.apk`](GNDROiD_Companion.apk)**

### Install via ADB (Connected Phone or Virtual Machine):
```powershell
adb install -r GNDROiD_Companion.apk
```

### Install Manually:
1. Transfer `GNDROiD_Companion.apk` to your Android device via USB, Google Drive, or local network.
2. Tap the APK file and select **Install** (enable *Install unknown apps* if prompted).
3. Open **GNDROiD Link** and tap **🚀 1-Tap Enable All Permissions**.
4. Tap **⚡ Start Pure Wireless Mirror (Port 51880)** to activate the wireless bridge.
